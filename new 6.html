1

Basic if / elif / else

Remember:
if checks the first condition.
elif checks another condition if the previous condition was false.
else runs when all previous conditions are false.

Only one branch of an if/elif/else structure will run.

Problem: Temperature Warning

A weather station records the current temperature. Write a Python program that asks the user to enter the temperature in °C.

Your program must:

  • Output "It's hot!" if the temperature is 30 or above.
  • Output "The weather is warm." if the temperature is 20–29.
  • Output "The weather is cool." if the temperature is 10–19.
  • Output "It's cold!" for temperatures below 10.
Challenge: Test your program with at least four different temperatures.

Comparison & Logical Operators

You can use comparison operators to compare values.

Operator Meaning Example
== Equal to x == 5
!= Not equal to x != 0
> Greater than x > 10
< Less than x < 100
>= Greater than or equal x >= 18
<= Less than or equal x <= 50

Logical operators combine conditions:

  • and — both conditions must be true.
  • or — at least one condition must be true.
  • not — reverses a Boolean value.

3

CASE OF Statements

In Cambridge pseudocode, CASE OF allows a program to choose between several possible values. 

INPUT Move

CASE OF Move
    'W' : Position ← Position - 10
    'S' : Position ← Position + 10
    'A' : Position ← Position - 1
    'D' : Position ← Position + 1
    OTHERWISE : OUTPUT "Invalid movement"
ENDCASE

Nested Conditions

A nested if is an if statement inside another if statement.

A theme park has a roller coaster with the following rules:

  • The rider must be at least 120 cm tall.
  • Riders under 12 years old must have an adult with them.
  • Riders aged 12 or above can ride without an adult.

Ask the user for:

  • Age
  • Height
  • HasAdult

Your program should give a useful message explaining the result.

For example:

You need an adult with you.

Challenge: Use nested IF statements so that different error messages can be displayed.

Common Mistakes

Watch out for these mistakes:

  • Using overlapping conditions.
  • Putting conditions in the wrong order.
  • Forgetting the else case.
  • Forgetting ENDCASE in pseudocode.
  • Forgetting ENDIF in pseudocode.
  • Not handling invalid input.
