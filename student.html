Problem 01

Temperature Warning

A weather station records the current temperature. Write a program that asks the user to enter the temperature in °C.

Your program must:

  • Output "It's hot!" if the temperature is 30 or above.
  • Output "The weather is warm." if the temperature is 20–29.
  • Output "The weather is cool." if the temperature is 10–19.
  • Output "It's cold!" for temperatures below 10.
Challenge: Test your program with at least four different temperatures.

Cinema Ticket Checker

Ask the user for:

  • Age
  • HasAdult — enter yes or no

The program should output "Entry allowed" or "Entry denied".

Problem 03

Robot Movement

You are programming a robot on a grid. The robot starts at position 50.

Ask the user to enter a movement:

  • W → move up by 10
  • S → move down by 10
  • A → move left by 1
  • D → move right by 1
  • Anything else → output "Invalid movement"

Write the solution using a CASE OF statement.

Challenge: Add a second variable to represent the robot's vertical position.

Theme Park Ride Checker

  • The rider must be at least 120 cm tall.

Ask the user for Age, Height, and HasAdult. Your program should give a useful message explaining the result — for example "You are too short.", "You need an adult with you.", or "You can ride the roller coaster!"

Challenge: Use nested IF statements so that different error messages can be displayed.

Problem 05

Grade Calculator

A school uses the following grading system:

  • 80–100 → A
  • 70–79 → B
  • 60–69 → C
  • 50–59 → D
  • Below 50 → U

Write a program that asks the user to enter a mark and outputs the correct grade. If the mark is below 0 or above 100, output "Invalid mark".

Challenge: Make sure every possible mark is handled correctly.

Game Shop Discount

  • 5 or more games → 20% discount

Final Challenge

School Sports Competition

You are writing a program to decide whether a student can enter a school sports competition. Ask the student for Age, Height, and FitnessScore.

The student can enter if:

  • They are 13 or older.
  • Their height is at least 150 cm.
  • Their fitness score is 60 or higher.

Give a different message for each problem:

  • Too young → "You must be at least 13."
  • Too short → "You must be at least 150 cm."
  • Fitness score too low → "Your fitness score is too low."
  • All requirements met → "You are accepted!"
Boss challenge: Use nested conditions, AND and/or OR, and comparison operators. Handle invalid fitness scores below 0 or above 100. Test your program with different inputs.
