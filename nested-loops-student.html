Challenge 1: Locker Rows

Medium[4]

Write 0478 pseudocode. Transpile & Run.

Northfield School is labelling the lockers in its new sports hall. The lockers are arranged in 4 rows. Each row has 2 more lockers than the row before it, so row 1 has 2 lockers, row 2 has 4 lockers, row 3 has 6 lockers and row 4 has 8 lockers. The lockers in each row are numbered starting from 1.

The caretaker wants a program that prints the locker numbers for each row on a separate line.

Write a program that uses nested FOR loops to output the locker numbers for every row.

Marking: 4 marks

  1. Runs and produces the correct output.[1]
  2. Uses nested FOR loops.[1]
  3. Inner loop produces the correct number of lockers for each row.[1]
  4. Correct spacing and new line after each row.[1]

Challenge 2: Robot Battery Grid

Medium[4]

Write 0478 pseudocode. Transpile & Run.

A warehouse robot patrols a charging area made up of 3 rows and 4 columns of battery stations. To work out how much charge each station needs, the engineers use this rule:

charge units = row number × column number

The engineers want a table showing the charge units for every station, one row of the grid per line.

Write a program that uses nested FOR loops to output the charge units for every station.

Marking: 4 marks

  1. Runs and produces the correct output.[1]
  2. Uses nested FOR loops.[1]
  3. Correctly calculates Row × Column.[1]
  4. Produces three rows with four values in each row.[1]

Challenge 3: Training Pyramid

Hard[4]

Write 0478 pseudocode. Transpile & Run.

A school robotics team is preparing for a competition with 5 rounds of training. The coach increases the workload each round:

  • Round 1: 1 exercise
  • Round 2: 2 exercises
  • Round 3: 3 exercises
  • and so on, up to round 5.

In each round, the exercises are numbered starting from 1. The coach needs a program that lists the exercise numbers for each round on its own line. The program must also keep a running count of every exercise performed and display it at the end.

Write a program that:

  • uses nested FOR loops to output the exercise numbers for each round
  • uses a variable called Total to count all the exercises performed
  • outputs TOTAL followed by the value of Total after the last round

Marking: 4 marks

  1. Runs and produces the required output.[1]
  2. Uses nested FOR loops.[1]
  3. Inner loop depends on the outer loop.[1]
  4. Correctly counts the 15 exercises.[1]

Challenge 4: Descending Seats

Hard[4]

Write 0478 pseudocode. Transpile & Run.

The Grand Theatre has 5 sections of seating. Section 5 is the largest and has 5 seats. Each section closer to the stage has one seat fewer, so section 1 has only 1 seat.

The manager wants a simple seating plan where each * represents one seat. The plan starts with section 5 and finishes with section 1, with one section on each line. After the plan, the program must display the total number of seats in the theatre.

Write a program that:

  • uses a loop that counts down from section 5 to section 1
  • uses a nested loop to output one * for each seat in the section
  • uses a variable called Total to count the seats
  • outputs TOTAL followed by the value of Total at the end

Marking: 4 marks

  1. Runs and produces the required output.[1]
  2. Uses a countdown loop.[1]
  3. Uses a nested loop to produce the stars.[1]
  4. Correctly calculates TOTAL 15.[1]

Challenge 5: First Available Locker

Hard[4]

Write 0478 pseudocode. Transpile & Run.

At the end of term, a caretaker checks six lockers to see which ones are free. Locker numbers are entered into a program one at a time. A locker is available if its number is even.

The six locker numbers entered are:

The caretaker only wants to know the first available locker, so the program must not output any later even numbers.

Write a program that:

  • uses a FOR loop to input the six locker numbers
  • uses the MOD operator to test whether each number is even
  • uses a Boolean variable called Found to make sure only the first available locker is output
