Problem 01~6 min

Temperature Warning

A weather station records the current temperature. Ask the user to enter the temperature in °C. Output "It's hot!" for 30+, "The weather is warm." for 20–29, "The weather is cool." for 10–19, "It's cold!" below 10.

Challenge: Test with at least four different temperatures.
Reveal solution 
DECLARE Temperature : REAL

INPUT Temperature

IF Temperature >= 30 THEN
    OUTPUT "It's hot!"
ELSE
    IF Temperature >= 20 THEN
        OUTPUT "The weather is warm."
    ELSE
        IF Temperature >= 10 THEN
            OUTPUT "The weather is cool."
        ELSE
            OUTPUT "It's cold!"
        ENDIF
    ENDIF
ENDIF
Watch for: students writing separate IF statements instead of ELSE IF chains — ask what happens to a temperature of 35 if every branch is a standalone IF.
Problem 02~6 min

Cinema Ticket Checker

Teenagers 13–17 need an adult with them; 18+ can enter alone. Ask for Age and HasAdult (yes/no). Output "Entry allowed" or "Entry denied".

Challenge: Use AND and/or OR to combine conditions.
Reveal solution 
DECLARE Age : INTEGER
DECLARE HasAdult : STRING

INPUT Age
INPUT HasAdult

IF Age >= 18 THEN
    OUTPUT "Entry allowed"
ELSE
    IF Age >= 13 AND HasAdult = "yes" THEN
        OUTPUT "Entry allowed"
    ELSE
        OUTPUT "Entry denied"
    ENDIF
ENDIF
Watch for: students forgetting under-13s should also be denied — walk through Age = 10 to confirm the logic falls through correctly.
Problem 03~7 min

Robot Movement

Robot starts at position 50. W/S/A/D move it up/down/left/right; anything else outputs "Invalid movement". Solve with CASE OF.

Challenge: Add a second variable for vertical position.
Reveal solution 
DECLARE Move : CHAR
DECLARE Position : INTEGER
DECLARE VerticalPosition : INTEGER

Position <- 50
VerticalPosition <- 50

INPUT Move

CASE OF Move
    'W' : VerticalPosition <- VerticalPosition - 10
    'S' : VerticalPosition <- VerticalPosition + 10
    'A' : Position <- Position - 1
    'D' : Position <- Position + 1
    OTHERWISE : OUTPUT "Invalid movement"
ENDCASE
Watch for: forgetting ENDCASE, and using = instead of <- for the initial assignment — a very common mark loss in the actual exam.
Problem 04~7 min

Theme Park Ride Checker

Rider needs 120cm+ height. Under-12s also need an adult; 12+ can ride alone. Ask Age, Height, HasAdult and give an explanatory message.

Challenge: Use nested IFs so different error messages display.
Reveal solution 
DECLARE Age : INTEGER
DECLARE Height : INTEGER
DECLARE HasAdult : STRING

INPUT Age
INPUT Height
INPUT HasAdult

IF Height < 120 THEN
    OUTPUT "You are too short."
ELSE
    IF Age < 12 THEN
        IF HasAdult = "yes" THEN
            OUTPUT "You can ride the roller coaster!"
        ELSE
            OUTPUT "You need an adult with you."
        ENDIF
    ELSE
        OUTPUT "You can ride the roller coaster!"
    ENDIF
ENDIF
Teaching point: this is the clearest example of true nesting on the sheet — height gates everything, then age nests inside. Ask students to identify which condition should be checked first and why (height applies to everyone).
Problem 05~7 min

Grade Calculator

80–100 A, 70–79 B, 60–69 C, 50–59 D, below 50 U. Below 0 or above 100 → "Invalid mark".

Challenge: Make sure every possible mark is handled.
Reveal solution 
DECLARE Mark : INTEGER

INPUT Mark

IF Mark < 0 OR Mark > 100 THEN
    OUTPUT "Invalid mark"
ELSE
    IF Mark >= 80 THEN
        OUTPUT "A"
    ELSE
        IF Mark >= 70 THEN
            OUTPUT "B"
        ELSE
            IF Mark >= 60 THEN
                OUTPUT "C"
            ELSE
                IF Mark >= 50 THEN
                    OUTPUT "D"
                ELSE
                    OUTPUT "U"
                ENDIF
            ENDIF
        ENDIF
    ENDIF
ENDIF
Watch for: checking the invalid-mark condition first — if it's checked last, a mark of 150 would incorrectly fall into no grade band and needs a final catch-all anyway. Checking it first is cleaner and matches exam mark schemes.
Problem 06~6 min

Game Shop Discount

Ask price per game and number of games. 5+ games → 20% off, 3–4 → 10% off, 1–2 → 0%. Output final price.

Challenge: Display the discount amount as well as the final price.
Reveal solution 
DECLARE Price : REAL
DECLARE NumberOfGames : INTEGER
DECLARE Discount : REAL
DECLARE FinalPrice : REAL
DECLARE TotalPrice : REAL

INPUT Price
INPUT NumberOfGames

TotalPrice <- Price * NumberOfGames

IF NumberOfGames >= 5 THEN
    Discount <- TotalPrice * 0.20
ELSE
    IF NumberOfGames >= 3 THEN
        Discount <- TotalPrice * 0.10
    ELSE
        Discount <- 0
    ENDIF
ENDIF

FinalPrice <- TotalPrice - Discount

OUTPUT "Discount amount: ", Discount
OUTPUT "Final price: ", FinalPrice
Watch for: applying the discount percentage to the single game price instead of the total — a good chance to discuss calculating TotalPrice first.
Problem 07~6 min

Security Door

Door opens if (HasCard AND CorrectPIN) OR IsAdmin. Output "Access granted" or "Access denied".

Challenge: Complete a truth table for HasCard and CorrectPIN.
Reveal solution 
DECLARE HasCard : BOOLEAN
DECLARE CorrectPIN : BOOLEAN
DECLARE IsAdmin : BOOLEAN

INPUT HasCard
INPUT CorrectPIN
INPUT IsAdmin

IF (HasCard = TRUE AND CorrectPIN = TRUE) OR IsAdmin = TRUE THEN
    OUTPUT "Access granted"
ELSE
    OUTPUT "Access denied"
ENDIF
Teaching point: good moment to run the AND/OR truth tables on the board live — ask what happens if brackets are removed and precedence changes.
Final Challenge~8 min

School Sports Competition

Enter if Age ≥ 13, Height ≥ 150cm, FitnessScore ≥ 60. Separate messages per failing condition; handle FitnessScore outside 0–100 as invalid.

Boss challenge: nested conditions, AND/OR, comparison operators, invalid fitness score handling, multiple test runs.
Reveal solution 
DECLARE Age : INTEGER
DECLARE Height : REAL
DECLARE FitnessScore : INTEGER

INPUT Age
INPUT Height
INPUT FitnessScore

IF FitnessScore < 0 OR FitnessScore > 100 THEN
    OUTPUT "Invalid fitness score"
ELSE
    IF Age < 13 THEN
        OUTPUT "You must be at least 13."
    ELSE
        IF Height < 150 THEN
            OUTPUT "You must be at least 150 cm."
        ELSE
            IF FitnessScore < 60 THEN
                OUTPUT "Your fitness score is too low."
            ELSE
                OUTPUT "You are accepted!"
            ENDIF
        ENDIF
    ENDIF
ENDIF
Use this as the assessment problem — it combines every skill from the lesson (nesting, AND/OR, comparison operators, invalid input) in one solution. If time is short, this is the one problem not to cut.
